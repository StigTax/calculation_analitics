# calculation_analitics

Скрипт для ежемесячной аналитики по калькуляторам:
пользователи по регионам, скачивания отчётов, конверсия из захода в скачивание.
Заменяет ручной разбор выгрузки в Excel.

## Структура проекта

```
calculation_analitics/
├── config/
│   ├── excluded_users.csv     # логины, которых нужно исключить из аналитики
│   └── excluded_domains.csv   # домены, которые нужно исключить из аналитики
├── src/
│   ├── constants.py           # пути, имена колонок, справочник округов, пороги
│   ├── loader.py              # чтение xlsx + очистка (exclude-листы)
│   ├── utilits.py             # переиспользуемые фильтры/трансформации df
│   ├── aggregate.py           # три метрики + точка входа для ручного прогона
│   └── main.py                # CLI — пока пусто, см. ToDo
└── README.md
```

## Как запустить (текущее состояние — без CLI)

### Установка

Рекомендуемый способ:

```bash
python -m venv .venv

# Windows (bash, например Git Bash):
source .venv/Scripts/activate

# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

python -m src.aggregate
```

Путь к файлу выгрузки, exclude-листам и список доменов зашиты в `constants.py`
(`RAW_FILE`, `EXCLUDED_USERS_FILE`, `EXCLUDED_DOMAINS_FILE`, `DOMAINS`).
Печатает в консоль три таблицы (`top`, `regions`, `conversion`) по каждому
сайту из `DOMAINS`.

## Метрики — что именно считается

Три метрики используют **разные единицы измерения** — это осознанное решение,
не баг. Суммы между таблицами не обязаны биться друг с другом.

### Top — топ пользователей по скачиваниям
Считается только для `MAIN_DOMAIN` (`calc.saint-gobain.ru`) — только там
в логе есть логин пользователя. На остальных доменах (hub, vetonit)
пользователь анонимен, топ для них не считается (`None`).
Единица подсчёта — **события** (`.size()`): один человек, скачавший
5 раз, даёт 5, а не 1.

### Regions — уникальные пользователи по федеральным округам
Единица — `identity`: логин (если это `MAIN_DOMAIN` и логин указан)
или `Uuid` (во всех остальных случаях, включая пустой логин на главном
домене). Один и тот же человек, замеченный в разных регионах (сменил
локацию/VPN между визитами), учитывается в **каждом** регионе отдельно —
поэтому сумма по регионам может быть больше, чем число "скачал" в таблице
conversion.

### Conversion — конверсия из захода в скачивание
Единица — **сессия** (`session_id` из `add_session_id`): действия одного
`Uuid` группируются по времени, разрыв между соседними действиями больше
`SESSION_GAP_MINUTES` (сейчас 30 минут, подобрано по факту — 90-й
перцентиль реальных пауз ~14 минут) начинает новую сессию. Несколько
скачиваний внутри одной сессии считаются один раз — конверсия не может
превысить 100%. Логин не участвует, считается одинаково для всех сайтов.

Известное ограничение: если пользователь возвращается на уже открытую
страницу спустя долгое время и сразу скачивает — такая сессия может не
содержать событие "Открыта страница" (на проверенных данных — единичные
случаи, на конверсию существенно не влияет).

## Конфигурация

- `MAIN_DOMAIN` / `DOMAINS` — какие сайты анализируем и как их подписывать
  в отчёте.
- `excluded_users.csv` / `excluded_domains.csv` — служебные/тестовые
  пользователи и старые/staging-домены, которые не должны попадать
  в аналитику. Пополняются по мере обнаружения новых.
- `FEDERAL_DISTRICTS` / `REGION_TO_DISTRICT` — статичный справочник
  регион → округ. При добавлении нового региона в лог, которого нет
  в справочнике, `uniq_users_by_region` печатает предупреждение
  "Нет в справочнике округов".
- `SESSION_GAP_MINUTES` — порог разрыва между действиями одного Uuid
  для разбивки на сессии.
